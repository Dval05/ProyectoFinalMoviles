# Informes Técnicos LaTeX 📝

Esta carpeta contiene el código fuente de los documentos obligatorios para evaluación (Tercer parcial e Informe Final).

Hemos empleado LaTeX debido a que permite un formato estrictamente académico, numeración dinámica y referencias cruzadas sin los errores de maquetación típicos de procesadores de texto convencionales.

## Contenido

*   **`Informe_3_2.tex`**: Corresponde a la evaluación del deber del Tercer Parcial. Enumera detalladamente las pantallas realizadas, la configuración inicial del entorno, las arquitecturas seleccionadas y los hitos alcanzados previo a la fase rigurosa de control de calidad.
*   **`Informe_Final.tex`**: El documento maestro para el examen teórico final (3 puntos). Detalla todo el problema, los objetivos generales y específicos (despliegues de la aplicación, uso de sensores de hardware y geolocalización), la estructura transaccional de Firebase, el marco de pruebas E2E consolidado, e inserta directamente la evidencia del proyecto.
*   **`referencias.bib`**: Base de datos de citaciones estilo IEEE.
*   **`img/`** (Carpeta): Directorio donde el desarrollador debe arrojar las capturas de pantalla reales (en formato PNG) para que el compilador las ensamble automáticamente.

## ¿Cómo generar los PDFs?

Recomendamos el uso de la herramienta web **Overleaf** o un compilador local (`pdflatex`).

1.  Comprime toda esta carpeta `informes_latex/` (asegurándote de que tenga la carpeta `img` con tus fotos en su interior) en un archivo `.zip`.
2.  Súbelo a Overleaf y haz clic en *Compilar*.
3.  ¡Disfruta de tus PDFs en calidad premium listos para imprimir y entregar!
